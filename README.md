# PTT 發文稿酬（P 幣）計算器

**[▶ 開啟計算器](https://dube116.github.io/ptt-money-calculator/)**

貼上文章即時估算發文可獲得的 P 幣，並標出哪些內容有計分、哪些被去重或排除。
依 2026/11/01 約 05:00 之後的**現行版本**推測規則計算，**非官方公式**，站方可能隨時調整。

---

## 1. 背景

2026/10 PTT 改版發文稿酬：不再看游標移動或按鍵間隔，只看內容。
GitHub 上 [pttbbs](https://github.com/ptt/pttbbs) 的 `calc_post_entropy()` 是預設實作（計有效字元的位元組數），
站上實際使用的版本不同且不公開（函式宣告為 `GCC_WEAK`，可由站方覆蓋）。

本計算器的規則，是以實際文章的稿酬（BBS 文章資訊 `Q` 顯示的價格）配合 ptt.cc 上的全文反推而得。

## 2. 推測規則（現行版本，2026/11/01 約 05:00 起）

```
詞元   = 每個漢字 → 一個詞元
         每個英數串（英文字母、數字、_ 連在一起的一串，純數字也算）→ 一個詞元，不論長短
         日文假名、注音、全形標點與符號、全形英數、半形符號、色碼控制碼 → 不算
分數   = 每個詞元 2 分，每個不同詞元最多算 2 次
不計入 = 引用行（: 開頭）、所有 ※ 開頭的行（含看板發文提醒範本）、
         內文第一個單獨 -- 行之後（簽名檔）、網址
基本   = 分數 × 0.05 四捨五入（＝詞元數 × 0.1），上限 150P（分數 10 以上才有 1P）
遞減   = 基本 − 3 × 當天（0:00 起）在這篇之前「實拿 5P 以上」的篇數，最低 1P
最後   = [新聞] 最多 5P、[情報] 最多 30P（回文不受限）；Fw: 轉錄 0P
```

當日篇數只計**實拿 5P 以上**的文章，4P 以下的不計入，所以短文連發通常不會被扣。
11/01 改版前是「有拿到稿酬就計入」（原始碼中 `StatIncDailyPost()` 位於 `if (money > 0)` 之內），
改版當天 05:00 前發的文仍照舊規則計入。

## 3. 驗證

11/01 新版（ALLPOST 作者搜尋取得 40 位作者 10/29～11/04 的完整發文序列與稿酬，
配合 ptt.cc 全文；排除發文後編輯過的文章）：

| 項目 | 樣本 | 完全命中 |
|---|---|---|
| 基本公式：「基本 − 實拿」為 3 的倍數（與遞減規則無關的檢驗） | 789 | 782 |
| 當日遞減：扣除額可確定的文章 | 450 | 447 |
| 全部（含實拿 1P、只能確定扣除額下限的文章） | 848 | 836 |
| 分數剛好在 .5 邊界的取整 | 56 | 53 篇進位、0 篇捨去（3 篇為其他因素） |

已知仍會不準的情況：

- **直接貼新聞內文**：實拿常只有計算值的一半左右，可能有轉貼偵測。
- **看不到的前文**：當天在隱藏看板或已刪除的文章（實拿 5P 以上）仍計入篇數 → 實拿比預測少。
- **發文後編輯**：稿酬以發文當下的內容計算。
- **舊版連線**：PTT 更新程式後，已登入的連線會沿用舊版直到重新登入。

被否定的假設（均顯著降低命中率）：標題計分、捨去或無條件進位、比例 0.049～0.052、
英數詞按字數計分、假名與注音計分、全形標點計分；遞減方面：有稿酬就計入篇數、
門檻 4P 或 6P、以扣除前的基本稿酬判斷門檻、滾動時間窗口、同 IP 篇數、登入以來篇數。

## 4. 規則演變（觀察到的版本）

| 期間 | 當日遞減 | 基本公式 |
|---|---|---|
| 10/21 改版初期 | 不扣 | 比例 0.08、門檻 40，純數字也算分 |
| 10/22 白天 | 每篇 −1P | 比例 0.08、門檻 40 |
| 10/22 深夜 | 每篇 −3P | 比例 0.08、門檻 40 |
| 10/27 11:59 起 | 每篇 −3P | 比例 0.1 捨去、無有效門檻、全形數字不算 |
| **11/01 約 05:00 起** | **每篇 −3P，只計實拿 5P 以上的文** | **只算漢字與英數串、每個詞元 2 分、純數字也算、比例 0.05 四捨五入** |

同一時間點，未重新登入的舊連線會繼續套用舊版規則。
10/27 pttbbs 新增 `CONFIG_ENTROPY_SVC`，稿酬改由站方私有的外部服務計算後回傳，
因此 11/01 的改版在原始碼中看不到。

## 5. 檔案

- `index.html`：頁面
- `calc.js`：計算核心（瀏覽器與 Node.js 共用）

頁面零外部載入資源，可離線使用；草稿只存在瀏覽器的 localStorage。
